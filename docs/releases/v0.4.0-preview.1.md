# IT Toolkit v0.4.0-preview.1

Bu sürüm, sistem araçlarını yalnızca başlatan bir arayüzden izlenebilir bir
teknisyen çalışma merkezine geçişin ilk adımıdır.

## Öne çıkanlar

- Yeni **Görev Merkezi**
- Normal görevlerde canlı komut çıktısı
- Yüzde bilgisi bulunan çıktılarda otomatik ilerleme
- Sürekli ping gibi uygun işlemleri iptal etme
- Son 100 görevi yerel olarak saklayan geçmiş
- Başarı, uyarı ve hata bildirimleri
- Çıktıyı kopyalama ve UTF-8 rapor dışa aktarma

## Görev davranışı

Uygulama standart oturumdaysa UAC isteyen işlemler ayrı yönetici penceresine
devredilir. Windows güvenlik sınırı nedeniyle bu harici pencerenin canlı çıktısı
uygulamaya alınamaz; Görev Merkezi bunu açıkça belirtir.

Uygulama zaten yönetici olarak çalışıyorsa aynı görevler yönetilen süreçte
çalışır ve uygun komutların çıktısı canlı izlenebilir.

## Kalite

- Başarılı görev, hata kodu, iptal, geçmiş temizleme ve yarım kalan oturum
  senaryoları otomatik testlerle doğrulandı.
- GitHub Build ve Release iş akışları artık EXE oluşturmadan önce testleri
  çalıştırıyor.
- Bütün uygulama ekranları ve gerçek salt-okunur Windows ağ komutu entegrasyon
  testinden geçirildi.

## Bilinen durumlar

- EXE henüz kod imzalı değildir; Windows SmartScreen uyarı gösterebilir.
- Harici UAC görevlerinin kesin tamamlanma sonucu uygulama tarafından bilinmez.
- Bazı eski Windows araçları düzenli yüzde çıktısı üretmediği için bu görevlerde
  belirsiz ilerleme göstergesi kullanılır.

## İndirme

`IT_Toolkit_v0.4.0-preview.1.exe` dosyasını indirin. Yanındaki `.sha256`
dosyası indirme bütünlüğünü doğrular.
