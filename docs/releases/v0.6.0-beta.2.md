# IT Toolkit v0.6.0-beta.2

Beta 2; Akıllı Tanılama sonuçlarını müşteriye teslim edilebilir bir rapora
dönüştürüyor, sahadan güvenli geri bildirim toplamayı kolaylaştırıyor ve yeni
sürümlerin uygulama içinden doğrulanarak kurulmasını sağlıyor.

## Öne çıkanlar

- GitHub Releases üzerinden uygulama içi güncelleme denetimi
- SHA-256 doğrulamalı indirme ve kullanıcı onaylı yeniden başlatma
- Teknisyen notları ile HTML/PDF müşteri teslim raporu
- Dizüstü ve masaüstü cihazlara özel güvenli kullanım önerileri
- Dönen yerel hata günlüğü ve hassas veri maskeleme
- Önceden doldurulan GitHub geri bildirim ekranı

## Yeni

### Güncelleme merkezi

Sol menüdeki **Güncellemeler** düğmesi GitHub’daki resmi yayınları denetler,
sürüm notlarını gösterir ve yeni EXE’yi arka planda indirir. Beta kullananlar
yeni beta/RC/kararlı yayınları; kararlı sürüm kullananlar yalnızca kararlı
yayınları görür.

İndirilen dosya, Release varlığındaki SHA-256 özetiyle eşleşmeden kurulmaz.
Güncelleme ancak kullanıcı onayından sonra başlar; mevcut EXE yedeklenir, yeni
sürüm yerleştirilir ve uygulama yeniden açılır. Kaynaktan çalıştırma modunda
Python kaynakları değiştirilmez.

### Müşteri teslim raporu

Akıllı Tanılama ekranına teknisyen notu alanı ile HTML ve PDF dışa aktarma
seçenekleri eklendi. Rapor; puanı, cihaz türünü, bulguları, ölçülen kanıtları,
güvenli önerileri ve teknisyen notlarını yazdırmaya uygun bir düzende sunar.
Hassas veriler paylaşım öncesinde maskelenir.

### Cihaza özel öneriler

Kasa türü ve pil bilgisi kullanılarak cihazın dizüstü/taşınabilir veya
masaüstü/sabit sistem olduğu belirlenir. Raporda cihaza uygun, salt öneri
nitelikli üç güvenli bakım maddesi gösterilir.

### Hata günlüğü ve geri bildirim

Uygulama başlangıcı, kapanışı, yakalanmayan hatalar ve başarısız görevler yerel,
dönen günlük dosyalarına kaydedilir. Üst çubuktaki **Geri Bildirim** ekranından
kategori, açıklama ve yeniden üretme adımlarıyla GitHub issue formu açılabilir.
Kullanıcı yolu, e-posta, IP, MAC, ürün anahtarı ve yaygın gizli anahtar alanları
paylaşım öncesi maskelenir; hiçbir GitHub anahtarı uygulamaya gömülmez.

## İyileştirmeler

- Güncelleme denetimi açılıştan sonra arayüzü engellemeden çalışır.
- Yeni sürüm bulunduğunda sol menüde görünür bir bildirim gösterilir.
- PDF bulgu kartları sayfalar arasında bölünmez.
- Rapor dışa aktarma sonucu Görev Merkezi geçmişine yazılır.
- Her yayın öncesi açık uygulama geri bildirimlerini kontrol etme adımı
  geliştirici rehberine zorunlu kural olarak eklendi.

## Güvenlik

- Güncelleme yalnızca `EddizEge/IT-Toolkit` resmi GitHub Release varlıklarından
  alınır.
- Dosya adı sürüm etiketiyle tam eşleşmeli ve SHA-256 doğrulaması geçmelidir.
- Güncelleme kullanıcı onayı olmadan mevcut EXE’yi değiştirmez.
- Günlük ve rapor metinleri paylaşılmadan önce hassas veri maskelemesinden geçer.

## Bilinen sorunlar

- Windows SmartScreen, kod imzası bulunmayan taşınabilir EXE için uyarı
  gösterebilir.
- Güncellemenin mevcut EXE’nin yerine geçebilmesi için uygulamanın bulunduğu
  klasörde yazma izni gerekir.
- PDF yazı tipi görünümü, cihazdaki kullanılabilir Windows yazı tipine göre çok
  küçük farklılıklar gösterebilir.

## Doğrulama özeti

- 44 otomatik test başarılı
- Ruff kod denetimi ve Python derleme kontrolü başarılı
- Güncelleme sürüm seçimi, doğru EXE varlığı ve SHA-256 hata senaryoları testli
- 1080×700 ve 1280×820 masaüstü arayüz kontrolleri tamamlandı
- İki sayfalık A4 müşteri PDF’i görsel olarak doğrulandı
- Yayın başlangıcında açık `[Uygulama Geri Bildirimi]` sayısı: **0**

## İndirme

`IT_Toolkit_v0.6.0-beta.2.exe` dosyasını indirin. Aynı yayındaki
`.sha256` dosyası indirilen EXE’nin bütünlüğünü doğrulamak içindir.
