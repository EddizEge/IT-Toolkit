Proje v1.0’a ulaşana kadar yalnızca en güncel yayın kanalı desteklenir.

## Açık bildirme

Bir güvenlik açığı bulduysanız ayrıntıları herkese açık issue’ya yazmayın.
GitHub deposundaki **Security → Report a vulnerability** alanını kullanın.
Özel güvenlik bildirimi henüz etkin değilse geliştiricinin GitHub profili
üzerinden özel iletişim kanalı isteyin.

Bildirimde mümkünse şunları ekleyin:

- Etkilenen sürüm
- Windows sürümü
- Sorunu yeniden üretme adımları
- Beklenen ve gerçekleşen davranış
- Olası etki
- Varsa güvenli düzeltme önerisi

## Güvenlik sınırları

IT Toolkit yönetici yetkisi gerektirebilen sistem işlemleri yürütür. Proje:

- Parola veya lisans anahtarı toplamamalı,
- Kullanıcı verisini uzak sunucuya göndermemeli,
- Korsan/çatlak yazılım dağıtmamalı,
- Resmi olmayan aktivasyon yöntemleri içermemeli,
- Kritik değişiklikleri kullanıcıya açıklamadan uygulamamalıdır.
